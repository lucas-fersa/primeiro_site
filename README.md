## 📌 Sobre o Projeto

Este é o **meu primeiro site desenvolvido em HTML5**, criado como atividade prática do curso de Desenvolvimento de Sistemas na ETEC. 

O objetivo do projeto é construir uma página web simples e estruturada que organiza uma lista com os meus **sites favoritos**. A página apresenta o nome de cada plataforma, uma imagem representativa, uma breve descrição sobre suas funcionalidades e um link direto para o acesso.

---

## 🚀 Tecnologias e Conceitos Aprendidos

Neste projeto, apliquei os conceitos fundamentais de estruturação web utilizando:

- **HTML5:** Utilizado para construir toda a estrutura semântica do site.
- **Tags de Cabeçalho (`<h1>`):** Organização e hierarquia dos títulos.
- **Parágrafos (`<p>`):** Apresentação das descrições de cada site.
- **Imagens (`<img>`):** Inserção de logos com atributos de acessibilidade (`alt`) e controle de dimensão (`width`).
- **Links Extensivos (`<a>`):** Redirecionamento para sites externos utilizando o atributo `target="_blank"` para abrir em uma nova aba.
- **Metadados (`<meta>`):** Configuração de codificação de caracteres (`UTF-8`) e responsividade (`viewport`).
